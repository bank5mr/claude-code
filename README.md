# 한칸

직접 만든 국어 학습 자료(PDF)를 판매하는 사이트.

- Next.js 16 (App Router) + TypeScript + Tailwind CSS 4
- Supabase (Auth, Postgres, Storage) — 2단계부터
- 토스페이먼츠 결제위젯 — 4단계부터

## 로컬 실행

```bash
npm install
npm run dev
# http://localhost:3000
```
